**Automotive Electrical Surge &amp; Overstress Monitoring System (Combined Model)** A complete, dual-channel analog front-end and LTspice simulation model designed to detect, scale, and capture ISO 7637-2 and ISO 16750-2 automotive transients (Pulses 1, 2a, 2b, 3a, 3b, and 5a). Combines frequency-compensated 30:1 positive attenuators, 44:1 negative inverters, anti-saturation active peak detectors with MOSFET reset, and sub-40 ns high-speed comparators for real-time MCU peak-voltage sampling and pulse-duration logging.
